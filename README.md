# Today Tool - v1.1 FINAL

A minimal, analog-inspired task manager for daily planning, designed to be ADHD-friendly and distraction-free.  
Inspired by [Ugmonk's analog system](https://ugmonk.com/en-au/pages/analog).  

💻 **Try it live:** [Today Tool Online](https://your-public-link-here)

## Features

- Three cards: **Today**, **Next**, **Completed**
- Unlimited tasks with default height for 10 tasks (scrollable)
- Task status: • (default), ✓ (completed), → (in progress)
- Move tasks between cards using **T/N/C** buttons
- Delete tasks with ✕ button
- Add new task via **Enter key**
- Hide/show Next & Completed cards
- Tasks persist across page reloads

## Usage

1. Type a task in the Today input and press **Enter** or click **Add**.  
2. Click status circle to toggle: default → completed → in progress.  
3. Move tasks between cards using **T/N/C** buttons.  
4. Delete tasks with ✕ button.  
5. Toggle visibility of Next & Completed cards with the switch.
